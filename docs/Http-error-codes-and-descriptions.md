## HTTP Error Codes and Description
List of error codes with description

| S/N | HTTP Error Code | Description                                         |
|-----|----------------|-----------------------------------------------------|
| 1   | 404            | No message is available, normally when the API specified is wrong |
| 2   | 401            | Unauthorised                                        |
| 3   | 200            | OK                                                 |
| 4   | 409            | Conflict                                           |
