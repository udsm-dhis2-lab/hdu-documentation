# Core Data Sending APIs and Their DataTemplates

The **HDU platform** provides a set of APIs that allow healthcare systems to transmit **structured health data** to the national digital health ecosystem.

These APIs use the **DataTemplate standard** to ensure that health data generated by different systems follows a **consistent structure**.

Through these APIs, healthcare systems can:

- Register and update client records  
- Submit clinical service data  
- Exchange laboratory information  
- Share health records across facilities  

Each API uses a **specific DataTemplate structure** depending on the type of information being exchanged.



## Types of DataTemplate APIs

The HDU platform supports three main **DataTemplate API categories**:

| API Type | Purpose |
|--|--|
| **Lab DataTemplate** | Used for transmitting laboratory requests and results |
| **Client Registry DataTemplate** | Used for registering and updating client information |
| **Shared Health Records DataTemplate** | Used for sharing clinical records across health facilities |

Each of these APIs uses a **structured JSON payload composed of DataTemplate blocks**.



## General DataTemplate API

The **General DataTemplate API** is the primary API used by **EMR and EHR systems** to send health service data captured during patient visits.

This API supports submission of multiple blocks including:

- Demographic information  
- Visit details  
- Clinical observations  
- Laboratory requests  
- Diagnoses  
- Treatments  
- Billing details  
- Referral information  



## DataTemplate Submission API

| Field | Value |
|------|------|
| **Method** | POST |
| **Endpoint** | `/api/v1/hduApi/dataTemplates` |
| **Message Type** | JSON |
| **Authentication** | Basic Authentication |



## Example: DataTemplate Submission Request

```json
{
  "templateDetails": {
    "code": "GENERAL",
    "id": "general",
    "name": "General"
  },
  "data": {
    "facilityDetails": {
      "code": "109601-5",
      "name": "Sample Health Facility"
    },
    "listGrid": [
      {
        "demographicDetails": {
          "mrn": "109601-5-129022102/2023",
          "firstName": "Aminata",
          "lastName": "Haule"
        },
        "visitDetails": {
          "id": 400388,
          "visitDate": "2024-08-03"
        }
      }
    ]
  }
}
```
This payload represents a DataTemplate containing a client visit record that will be processed by the HDU platform.

# Mandatory Blocks for Client Data Submission

When sending **client data that has already been registered in the system**, the following blocks must be included in the **DataTemplate payload**.

| Block | Required Parameter |
|------|-------------------|
| facilityDetails | HFRCode |
| demographicDetails | MRN or preferred identifier |
| visitDetails | id |

These blocks allow the **HDU system** to correctly identify:

- The **facility**
- The **client**
- The **specific visit** being reported



# DataTemplate Metadata API

Before sending data, systems may retrieve available **DataTemplates** using the **metadata API**.

| Field | Value |
|------|------|
| Method | `GET` |
| Endpoint | `/api/v1/hduApi/dataTemplates` |
| Authentication | Basic Authentication |

This API returns metadata describing available templates, including:

- Template identifiers
- Template workflow
- Block structures
- Required parameters
