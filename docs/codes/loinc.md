# LOINC Standard Codes

LOINC codes are used within the HDU API to standardize laboratory tests, clinical observations, radiology, vaccinations, and prophylaxis data.

These APIs allow systems to retrieve and search LOINC codes used across laboratory and clinical workflows.

## LOINC APIs

| API | Method | Description |
|----|-------|-------------|
| /api/v1/hduApi/codeSystems/loinc | GET | Retrieve LOINC codes with pagination and filtering |
