# Concept of Data Templates

Data templates are composed of blocks known as **template blocks**. Each template block contains variables or parameters that define the structure of data being exchanged.

Parameters within a specific block are identified from MTUHA registers. MTUHA registers were the primary reference used in developing the data template structure.

The objective of the Data Template Standard is to ensure a uniform approach to data aggregation and processing for register-generated data when hospital systems communicate with data warehouse ecosystem components such as HMIS-DHIS2, eIDSR, and eTL.

## Source Registers

The initial MTUHA registers used to produce this version of the Data Template include:

- OPD
- IPD
- ANC
- Death Registry
- Child Health
- eIDSR
- Dental
