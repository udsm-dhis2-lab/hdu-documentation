

# Appointment Details (`appointment`)

## Overview

The **Appointment Details** block captures information related to scheduled or booked service appointments for a client.

It ensures that:

- Appointments can be uniquely identified and tracked  
- The status of appointments is clearly recorded  
- Linked payment and service information associated with the appointment is captured  
- Facilities can manage scheduling, service delivery, and follow-up activities effectively  

This block appears within each record in the `listGrid` array and may contain **one or more appointment records** for a client visit.



## Object Structure (Conceptual)

```text
appointment
├── appointmentId
├── hfrCode
├── appointmentStatus
├── paymentDetails
│   ├── controlNumber
│   ├── statusCode
│   └── description
└── serviceDetails
    ├── serviceCode
    ├── serviceName
    └── shortName
```

## Parameters

### `appointment`

* **Data type:** `array<object>`  
* **Description:**  
  Container holding one or more appointment records associated with a client visit.  
  Each entry represents a single scheduled appointment.



#### `appointmentId`

* **Data type:** `string`  
* **Description:**  
  A unique identifier for the appointment.  
* **Usage note:**  
  Used to reference and track the appointment across scheduling, billing, and service delivery systems.  
* **Example value:**  
  `394383938`



#### `hfrCode`

* **Data type:** `string`  
* **Description:**  
  Health Facility Registry (HFR) code of the facility where the appointment is scheduled.  
* **Example value:**  
  `34893`



#### `appointmentStatus`

* **Data type:** `string`  
* **Description:**  
  Current status of the appointment.  
* **Usage note:**  
  Typical values include `booked`, `completed`, `cancelled`, `rescheduled`.  
* **Example value:**  
  `booked`



## Appointment Payment Information

#### `paymentDetails`

* **Data type:** `array<object>`  
* **Description:**  
  Captures payment transaction details associated with the appointment.  
  The following parameters are defined within this object.



##### `controlNumber`

* **Data type:** `string`  
* **Description:**  
  A unique payment control or reference number generated by the payment system.  
* **Example value:**  
  `89385928359`



##### `statusCode`

* **Data type:** `string`  
* **Description:**  
  Status code returned by the payment processing system.  
* **Example value:**  
  `200`



##### `description`

* **Data type:** `string`  
* **Description:**  
  Descriptive message explaining the payment status.  
* **Example value:**  
  `This was successful`



## Service Details

#### `serviceDetails`

* **Data type:** `array<object>`  
* **Description:**  
  Captures information about services associated with the appointment.  
  The following parameters are defined within this object.



##### `serviceCode`

* **Data type:** `string`  
* **Description:**  
  Code identifying the service being scheduled.  
* **Example value:**  
  `012`



##### `serviceName`

* **Data type:** `string`  
* **Description:**  
  Human-readable name of the service.  
* **Example value:**  
  `Service A`



##### `shortName`

* **Data type:** `string`  
* **Description:**  
  Abbreviated or short name for the service.  
* **Example value:**  
  `S012`
