# Specialized Program Blocks



Specialized Program Blocks support program-specific reporting and workflows.

These blocks are designed to meet the requirements of:
- Reproductive, Maternal, Newborn, and Child Health (RMNCH)
- Family planning services
- Cancer screening programs
- Mortality and death registration
- Specialized clinics and vertical programs

They are typically conditionally required depending on the service provided.

## Structure of Specialized Program Blocks

```text

└── specialized-program-blocks
    ├── eye-clinic-details
    ├── antenatal-care-details
    ├── labor-and-delivery-details
    ├── vaccination-details
    ├── prophylaxis-details
    ├── family-planning-details
    ├── child-health-details
    ├── cpac-details
    ├── cecap
    ├── postnatal-details
    ├── causes-of-death-details
    ├── death-registry-details
    ├── contraceptives
    └── other-information
```
